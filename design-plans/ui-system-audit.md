# Velow UI 统一审核与建议

审核基线：`bc8e9ae25f0cf4e8cf933764a3a99c8998810268`。2026-09-12。

## Design language

- Audited surface：同一个 AppShell 下首页、计划、笔记（含每日灵感）、专注（含心流时间）及设置的源码路径。浏览器连接失败，未完成本轮全页面渲染、触控与放大验收；不宣称已达到国际标准。
- Design sources：当前 README、src/main.tsx 引入的 src/styles/tokens.css / reset.css / global.css、AppRoutes.tsx 和各页面实际导入的 CSS Modules。
- Documented decisions：保留原版 Velow Logo、品牌紫 #901D78、本地优先、44px 最小可点击目标、减弱动画支持。用户当前要求字体、配色、容器与交互统一，简洁高效、略带苹果风格。
- Governing owners and consumers：AppShell 提供全局导航和页面边距；tokens.css 提供颜色、16/24/32px 圆角、阴影和动效；页面模块局部覆写。
- Explicit exceptions：README 保留浅米黄纸张灵感卡片、紧凑无框知识树、单行任务标题；design-qa.md 保留计划冷蓝导航与青绿进度。计时数字不与普通页面标题强行同尺寸。点亮页独立品牌排版不纳入普通工作区字阶替换。

## Improve first

先处理第 1 项点击区域。它直接影响手机操作准确性，已有明确的项目约定，不需要改变用户认可的布局与功能。

## 统一规范建议（待确认，不是已实施或已认证的标准）

### 字体

- 统一正文的中英文系统字体回退链；不下载或嵌入苹果专有字体。原版 Logo 不变。
- 为工作区定义少量角色：页面标题、区域标题、正文、辅助说明、计时/统计数字。当前标题分散为 Focus 28px、Plans clamp(30px,8vw,46px)、Notes 手机 clamp(1.3rem,5.8vw,1.55rem)、Settings clamp(36px,7vw,64px)，需要先制作并排样张，再确定公共字阶，不能机械全部替换成相同值。
- 建议正文以当前灵感书写的 1rem 为阅读基准，标签和说明不得承担主要内容。长内容增加行高，目录维持紧凑；日期、时长使用等宽数字避免跳动。
- 将普通笔记的等宽 Markdown 编辑字体视为待评估项，不在没有样张验证时贸然切换编辑器或改变 Markdown 数据。

### 配色与容器

- 基础面板复用 canvas / surface / surface-muted / text / text-muted / brand / brand-soft；保留已认可的冷蓝周期导航、青绿状态和米黄灵感纸。
- 复用现有圆角角色：控件16px、卡片24px、大容器32px；用户指定的知识树14px标题框、无框树节点、8px纸张边角保持为显式例外。
- 同角色统一尺寸，不要求所有卡片固定高度。正文区随内容增长；弹层不截断操作；内容边距由 AppShell 和页面清晰分工，尤其复核专注页的额外水平16px和底部110px叠加。
- 苹果感来自留白、排版、细边界和有层级的操作，避免把每张卡片改成强玻璃、厚阴影或大紫色块。保留现有品牌玻璃卡片，只有渲染证据表明妨碍阅读时才调整。

### 交互与小巧思

- 主动作、次动作、危险动作使用固定语义；选中、按下、键盘焦点、禁用、保存中、失败状态都要明确。
- 保留知识树箭头展开、节点旁加号、完整路径；不可为了增大点击区把无框树重新改成方框列表。
- 保留月历记录圆点、轻柔计时呼吸、自动保存反馈，非必要动效尊重减弱动画设置。不新增装饰性按钮和空泛说明。
- “灵感日历”和“心流月历”共享月导航的视觉语法，但保留各自的内容语义；仅显示当月日期。统一键盘焦点、当前日期与选中日期的区分。
- 结束计时不自动完成任务；本地存储失败必须保留内容和明确重试。这些既有行为不能因视觉重构回退。

## 全页面验收清单

- 首页：空/有任务、长标题、真实功能入口、查看全部触控尺寸。
- 计划：日/周/月/学期、空学期、新建/编辑表单、任务操作、错误/撤销；保持单行任务标题和四种独立周期。
- 笔记：多根深层知识树、长路径、搜索、PDF、抽屉菜单、新建与自动保存、冲突/失败提示。
- 每日灵感：28/29/30/31天、跨年、空纸张、长内容、输入法与键盘遮挡。
- 专注：自由/关联、运行/暂停/结束、长任务标题、自定义时长错误、心流记录与月历。
- 设置/点亮页：明确未开放状态，保留品牌原稿，不把占位页当成完整设置功能。
- 响应式：320、390、428、768、1024、1440 CSS px；200%文字放大；横屏、安全区、软键盘、键盘导航、屏幕阅读器和减弱动画。
- 自动检查并不能替代人工触控/阅读检查；本轮没有进行新的浏览器验收或完整无障碍认证。

## 后续实施边界

本次只形成审核文档，没有修改产品源码。按照 improve-ui 技能，选定问题后再分别生成实施计划。首先修复明确问题，然后确认公共字阶样张，再落到全页面。保持数据模型、计划规则、笔记保存与计时逻辑不变；不合并旧的文件夹删除分支、不改变端口数据。

验收时执行：`pnpm verify`、适用的首页/计划/笔记浏览器测试，以及 `pnpm exec playwright test --config playwright.focus.config.ts`；随后在真实手机上核对实际尺寸、文本与关键流程。
