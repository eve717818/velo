# 知识树与每日灵感浏览器验收

日期：2026-09-08  
分支：`feat/notes-foundation`

## 验收结论

知识树与“每日灵感”已接入同一个笔记工作台。手机使用左侧目录抽屉，选择或新建文件夹/笔记后自动关闭，并在右侧显示完整路径与对应内容；“每日灵感”使用独立本地日期记录，不进入用户目录。

## 数据与保存

- Dexie v8 在保留 v1-v7 表结构的基础上新增 `dailyInspirations`，旧任务、周期、文件夹和笔记迁移测试通过。
- 日期键来自本地日历字段 `YYYY-MM-DD`，覆盖深夜本地时间、闰日、非法日期、0001 与 9999 年边界，不使用 UTC 转换。
- 未书写的日期不会创建记录；清空已有内容会删除记录及日历圆点。
- 320ms 自动保存、中文输入法组合输入、失败草稿保留、重试、修订冲突、卸载后的迟到保存保护均有组件回归。

## 浏览器流程

Chromium 生产构建验收 9/9 通过，覆盖：

- 组合输入期间不提前保存；组合结束后自动保存，刷新页面仍显示原日期与正文。
- 上一月、下一月、年份与月份直达，以及 390px 手机横向滑月。
- 有内容日期显示圆点；清空并刷新后正文为空且圆点消失。
- 卡片没有标题、日期、占位文字、正常保存状态、操作栏或回形针；正文无内部滚动条并随长内容增高。
- 手机从统一“新建”入口建立文件夹和子笔记，新建行显示完整父路径，成功后抽屉关闭并打开正确右侧页面。
- 回收站文件夹子树仍可浏览和恢复；普通笔记失败草稿与多页面修订冲突流程未回归。

## 响应式与无障碍

已验证 390×695、402×695、768×1024、834×1112、1024×900、1366×900：

- 页面无水平溢出。
- 日历日期行不重叠；日期、年月、前后月、“今天”和主要目录入口均至少 44×44px。
- 390/402px 下日历高 328px，纸张卡片最低约 446.8px，书写卡片高于日历。
- 手机显示目录抽屉；平板与桌面保留常驻左侧目录。
- `prefers-reduced-motion` 路径正常；每日灵感区域没有 serious / critical axe 违规。
