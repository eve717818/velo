# Velow Notebook 笔记工作区设计

日期：2026-09-05。状态：对话方案已确认，本文待用户复核后制定实施计划。

## 目标与边界

以 Markdown 正文和树状知识结构为核心，支持学生从收集、整理到复习打印的完整流程。延续白灰 Bento、品牌紫及少量冷色点缀；不重做已验收的计划栏。计划完成记录日历属于独立待办，不与灵感日历混用。

当前 NotesPage 为占位页；数据库已有 KnowledgeNode 与 NoteDocument，但采用 folder/note 分类和 JSON content，不能直接假定已具备 Markdown 编辑与任意节点正文能力。

## 信息架构

- 左侧：搜索、笔记收件箱、当日灵感、树状目录、回收站。
- 右侧：当前笔记编辑/阅读，或当日灵感日历与卡片；一次显示一个主要工作区。
- 推荐目录：专业 → 学科 → 章节 → 小节 → 内容要点。层级可跳过、重命名和继续细分，不设固定业务层数。
- 每个节点都可拥有正文及子节点；创建同级/子级、移动、重命名保持稳定 ID。禁止移动至自身或后代。
- 深层目录按需展开；面包屑可跳转，提供定位当前笔记。不得靠无限横向缩进挤压内容。
- 手机：正文优先，目录抽屉；平板横屏：左侧可调整宽度的常驻目录；竖屏：可收起目录。抽屉关闭恢复焦点。

## 编辑与保存

- Markdown 源文本为正文主数据；编辑、阅读、平板分栏预览三种模式。手机默认编辑/阅读切换。
- 逐步支持标题、列表、待办、引用、代码、表格、公式和图片；常用操作工具栏不取代 Markdown 输入。
- 中文输入法组合输入期间不得破坏文本、光标或提前触发快捷操作。
- 自动保存提供保存中/已保存/失败状态。异步保存以笔记 ID 和修订号隔离，切换笔记不得串写；失败保留草稿和重试入口，不能提示虚假成功。
- 离线可编辑；多标签冲突必须可发现，不能静默覆盖较新内容。
- 第一阶段具备软删除、恢复及基本 Markdown 导出。永久删除明确确认；子树删除与恢复整体处理，避免孤儿节点。
- 渲染过滤不可信 HTML 和危险链接，代码块只显示不执行；禁止默认加载不受控的远程内容。

## 收件箱与当日灵感

- 笔记收件箱接收未归类笔记、导入资料及未来录音转写。归档移动原记录，不复制、换 ID 或丢附件。
- 当日灵感按钮切换右侧为紧凑月历和每日卡片；默认今天，有内容日期显示标记，空日期不预建记录。
- 一天一卡，可追加多条带本地时间的灵感。支持编辑、删除和整理为笔记。
- 整理为笔记保留原灵感并建立关联，可归收件箱或选定节点。日期以本地日历日期存储，避免 UTC 偏移。
- 回形针仅作轻量卡片装饰或附件标识，不遮挡输入，也不制造无操作的伪按钮。

## 搜索、链接与批注

- 搜索标题和正文，可限制当前子树；包含灵感但明确结果类型。展示路径和命中片段，点击打开相应内容。
- 搜索派生索引可重建，不作为唯一正文存储；回收站内容默认不混入正常结果。
- 笔记链接显示 [[标题]]，关联稳定 ID；重命名与移动不破坏链接，同名可消歧。
- 批注关联笔记和正文锚点。正文变化导致无法定位时标记为待重新关联，不能绑到错误文字。

## PDF 复习打印

- 支持当前笔记或节点及全部后代，包含该节点自己的正文；沿树状排序依次输出。
- 顶部和节点菜单提供导出 PDF。首次确认选项，之后复用设置一键生成文件，不把系统打印弹窗冒充直接下载 PDF。
- 默认 A4、白底黑字、打印边距、章节标题、目录和页码。批注、图片、转写及 AI 总结可选择包含；音频本身不进入 PDF。
- 导出等待待保存内容成功，冻结一致的正文/排序快照；保存失败则阻止导出并保留草稿。
- 中文字体须具备嵌入许可并正确嵌入；公式、图片、长表格和代码分页不得裁切。目录页码对应最终分页。
- 大学科导出显示进度，可取消；图片、字体或某篇转换失败列明原因，不静默遗漏。
- 实现前用中文、数学公式、图片、长表格、长代码与多章节样稿验证生成引擎；移动端内存和文件保存也需实测。

## 数据与迁移

- 分离节点、Markdown 文档、附件、批注及每日灵感，以稳定 ID 关联；附件存本地 Blob，不把对象 URL 当持久地址。
- 在现有 Dexie 版本上追加迁移，不改写已发布迁移；保留旧 JSON 正文，并验证转换规则。无法可靠转换时保留原始数据并提示，不破坏或覆盖。
- 旧节点、首页最近笔记、现有计划数据均需兼容；标题同步规则明确为节点标题主导，正文不再维护独立冲突标题。
- 不引入服务器账号、云同步或把用户资料上传外部服务。HTTP 预览兼容继续保留；离线缓存仅在支持的安全上下文使用。

## 课堂录音与 AI：后续阶段

- 录音关联笔记，计划支持开始/暂停/继续/结束、回放和时间点标记；长音频分段落盘。
- 锁屏后台录音尚未确认，不承诺网页版持续录音。安卓原生壳与设备权限作为独立技术方案处理。
- 转写、拍照识别及 AI 总结保留原资料；上传前明确授权，学生确认后再采用内容，不自动覆盖正文或移动目录。

## 分阶段交付与验收

1. 基础闭环：树状目录、Markdown 编辑/阅读、收件箱、自动保存、软删除恢复和基本 Markdown 导出。验收首次空状态→新建→编辑→切换→重载恢复→移动→删除恢复→导出。
2. 检索与灵感：标题/正文搜索、目录范围筛选、每日灵感日历/卡片和整理为笔记；验证时区、空日期、重复整理和源内容保留。
3. 复习打印：图片、公式、表格及 PDF 导出；同时完善内部链接、批注。验收实际生成 PDF 的中文、分页、目录页码和打印可读性，而非仅浏览器预览。
4. 录音与 AI：按独立确认的权限、后台运行和模型配置方案实施。

每阶段提供手机/平板预览，不等待全套功能完毕才展示。至少覆盖 390/402、768/834、1024/1366 宽度；键盘可达、44px 点击目标、减少动画、存储失败和数据迁移回归。无物理设备验证时明确标注限制。
