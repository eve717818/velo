# Velow Notebook 笔记工作区重构设计

日期：2026-09-05

状态：对话设计已确认，待用户复核本文后制定实施计划。

## 目标与范围

把现有笔记工作区重构为简化版 Obsidian：左侧是可无限细分的树状目录，右侧是一张始终可直接书写的笔记页。界面强调结构清晰、书写安静和手机可用，不再把目录节点、笔记正文、Markdown 工具和多个显示模式混为一体。

本次重构包含文件夹与笔记分离、树状目录、搜索、所见即所得编辑、每日灵感、回收站和 PDF 导出。课堂录音、AI 总结、内部双向链接及云同步不进入本次实施范围；这些能力以后可以建立在新的文件夹和笔记模型上。

## 信息架构

左侧工作区从上到下固定为：

1. 笔记库标题与新建按钮。
2. 搜索框。
3. 每日灵感。
4. 导出 PDF。
5. 用户创建的无限层级目录树。
6. 回收站。

删除现有“笔记收件箱”入口及其归类逻辑。专业、学科、章节、小节只是推荐组织方式，不是固定业务层级。

文件夹与笔记完全分离：

- 文件夹只负责容纳子文件夹和笔记，没有自己的正文。
- 笔记只负责标题和正文，不能包含子节点。
- 所有节点使用稳定 ID；重命名、移动和排序不得改变 ID。
- 文件夹不能移动到自身或后代中。

右侧一次只显示一个主要页面：普通笔记、每日灵感、PDF 导出或回收站。

## 目录录入与树状交互

“笔记库”右侧提供一个主加号。点击后选择“新建文件夹”或“新建笔记”。每个文件夹右侧提供更多操作入口，包含：

- 新建子文件夹
- 新建笔记
- 重命名
- 移动
- 放入回收站

新建和重命名直接在当前树节点位置输入；回车保存，Esc 取消。新笔记默认创建在当前选中文件夹中；未选中文件夹时创建在根目录。

树状目录使用标准连接树：

- 同一父节点下的节点由连续竖线和短横线连接。
- 每级缩进约 12 像素，深层目录不会过早挤压标题空间。
- 每个节点包含折叠箭头、类型小图标和文字标题。
- 向下箭头表示展开，向右箭头表示收起；点击箭头只切换展开状态，点击标题才选中节点。
- 展开状态按设备保存在本地；打开某篇笔记时自动展开其完整路径。
- 提供“一键全部收起”，不提供默认全部展开。

目录标题始终单行显示。超过可用宽度时显示省略号，不得挤压箭头、图标、连接线和操作入口。桌面悬停显示完整标题；手机选中节点后，在右侧页面顶部路径或标题中显示完整名称。

## 普通笔记页

右侧普通笔记页始终处于可编辑状态，不提供“编辑／阅读／分栏”切换，也不显示二级标题、加粗、列表、引用、代码等格式工具栏。

用户体验采用完全隐藏 Markdown 符号的所见即所得方式：

- 顶部显示可直接修改的笔记标题和完整目录路径。
- 正文是一张连续书写页，点击任意位置即可输入。
- 正文直接显示最终排版效果，不显示 Markdown 源符号。
- 标题、段落、列表等结构通过自然键盘输入规则和粘贴内容识别产生，不依赖常驻工具栏。
- 中文输入法组合输入期间不得改变光标、拆分文字或提前保存错误内容。
- 页面不显示持续占位的“已保存”提示；仅在保存失败或发生冲突时显示明确、可操作的提醒。

结构化富文本作为新正文主数据，同时维护纯文本搜索字段。现有 Markdown 原文在迁移后保留为可恢复的兼容数据，不作为新编辑界面的直接输入源。

## 搜索

搜索同时匹配文件夹标题、笔记标题和笔记正文：

- 结果显示类型小图标、完整路径和正文命中片段。
- 点击文件夹结果时展开并定位目录。
- 点击笔记结果时展开路径并在右侧打开笔记。
- 回收站内容默认不进入普通搜索结果。
- 搜索索引属于可重建数据，不得成为正文唯一来源。

手机打开搜索结果后自动关闭目录抽屉并把焦点移到正文。

## 每日灵感

“每日灵感”是固定系统入口，不属于任何专业或学科文件夹。

右侧使用紧凑万年历：

- 可以选择任意年份和月份。
- 左右箭头逐月切换，手机支持水平滑动。
- 可以回到今天。
- 有内容的日期显示小圆点，当前日期和当前选中日期具有明确但克制的状态。
- 日历约占首屏三分之一，书写区域约占三分之二。

每个本地日历日期对应一张灵感卡片。选择日期后显示纯空白输入卡片：

- 卡片内没有标题、日期、提示、状态、操作文字或装饰性回形针。
- 卡片下方也不显示保存状态和操作行。
- 点击卡片只出现普通正文尺寸的细光标，立即开始输入。
- 内容为空或较少时保持统一最小高度。
- 内容增加时卡片随正文向下自然增长，不出现内部滚动条。
- 输入内容自动保存；只有失败时才在卡片之外显示错误提醒。

日期按用户本地日历日期保存，不能因 UTC 转换而移动到前一天或后一天。空日期不预先创建记录。

## 回收站

删除笔记或文件夹时执行软删除并永久保留，只有用户主动选择“彻底删除”或“清空回收站”才真正移除数据；永久删除必须二次确认。

删除文件夹时，文件夹及全部子文件夹、笔记作为一个整体进入回收站。恢复时：

- 原父文件夹仍存在，则完整恢复到原位置。
- 原父文件夹已经被彻底删除，则恢复到笔记库根目录。
- 恢复必须保留原有内部层级和排序。

回收站页面显示名称、类型、原路径和删除时间，支持单项恢复、整体恢复和永久删除。回收站中的内容不允许直接编辑。

## PDF 导出

“导出 PDF”是左侧固定入口，放在原“笔记收件箱”位置。导出范围跟随当前选中节点：

- 选中笔记时导出当前笔记。
- 选中文件夹时按树状目录顺序导出该文件夹及全部后代笔记。
- 没有选中节点时提示用户先选择文件夹或笔记。

文件夹导出自动生成封面、目录、层级标题和页码。默认使用 A4、白底黑字和适合打印店打印的页边距；中文字体必须正确嵌入。生成前等待当前正文保存完成，并冻结一份一致的数据和排序快照。任一笔记保存失败时阻止导出，不能静默遗漏内容。

导出过程显示进度并允许取消。生成成功后提供明确的 PDF 文件下载；不得把浏览器打印弹窗冒充 PDF 导出。

## 响应式布局

电脑与平板横屏使用双栏：左侧目录常驻并可调整宽度，右侧笔记占据剩余空间。目录可以临时收起。

手机和平板窄屏以正文为主：

- 点击顶部“目录”后，树状目录从左侧抽屉滑出。
- 选中笔记后抽屉自动收起。
- 抽屉保留完整树状连接线、折叠状态、搜索和固定入口。
- 关闭抽屉后焦点回到打开按钮或正文，不能丢失键盘位置。

触控目标不小于 44 像素；视觉缩进可以紧凑，但箭头和操作按钮的实际点击区域不能随之缩小。

## 数据模型与现有数据迁移

沿用 Dexie 本地数据库，在现有版本之后追加迁移，不改写已发布迁移。

主要实体职责：

- KnowledgeNode：文件夹或笔记节点，保存父节点、类型、标题、排序和删除信息。
- NoteDocument：只关联笔记类型节点，保存结构化正文、纯文本索引、修订号和时间。
- DailyInspiration：以本地日期为唯一键，保存当天结构化正文、纯文本和修订号。
- AppMeta：保存目录展开状态、迁移标志及可重建设置。

迁移必须在单个数据库事务中完成，失败则整体回滚：

- 现有没有子节点的节点保持为笔记，正文和 ID 不变。
- 现有有子节点但正文为空的节点转换为文件夹，子树保持不变。
- 现有有子节点且正文非空的节点转换为文件夹，并在其下创建一篇“概览”笔记承接原正文；原文档 ID、内容和时间信息保留，文档只重新关联到新笔记节点。
- 现有收件箱标志被移除；原收件箱根笔记移动到笔记库根目录，不删除内容。
- 重复标题允许存在，所有关联以稳定 ID 为准。

迁移后校验不得出现文件夹关联正文、笔记拥有子节点、孤儿节点、循环层级或丢失文档。校验失败时保留旧数据库状态并提示用户重试。

## 保存、冲突与错误处理

正文输入先写入本地草稿，再以防抖方式保存到 IndexedDB。异步保存以笔记 ID 和修订号隔离，切换笔记前刷新当前保存；旧笔记的迟到响应不得覆盖新笔记。

保存失败时保留本地草稿，并提供重试。检测到其他标签页的新修订时，不静默覆盖；用户可以重新载入当前版本或导出本地草稿。树节点新建、移动、删除和恢复均使用事务，部分失败不得留下半棵子树。

本次继续保持本地优先和离线可用，不新增账号、服务器同步或第三方上传。敏感正文和 PDF 内容不发送到外部服务。

## 验收与测试

服务和迁移测试至少覆盖：

- 文件夹与笔记类型约束。
- 无限层级、排序和禁止循环移动。
- 父文件夹整棵子树删除、恢复和永久删除。
- 原父节点缺失时恢复到根目录。
- 旧 Markdown 节点向文件夹／笔记分离模型无损迁移。
- 自动保存、修订冲突、本地草稿恢复和跨笔记切换。
- 每日灵感本地日期、空日期、不同时区及内容自动增长。
- 单篇与整棵文件夹 PDF 顺序、目录和失败阻断。

界面验收至少覆盖：

- 原始空状态到创建文件夹、子文件夹和笔记的完整流程。
- 树节点展开、收起、全部收起、连接线和长标题省略。
- 搜索文件夹、标题和正文并正确定位。
- 无格式工具栏、无编辑／阅读切换、正文直接输入。
- 每日灵感万年历任意年月跳转及纯空白卡片输入。
- 回收站整体恢复与永久删除确认。
- 手机左侧抽屉、平板横竖屏和电脑双栏。
- PDF 真实文件生成、中文字体、分页、目录页码和打印可读性。

响应式视口至少验证 390／402、768／834、1024／1366 像素宽度，并包含键盘导航、屏幕阅读器名称、减少动画和 44 像素触控目标检查。
